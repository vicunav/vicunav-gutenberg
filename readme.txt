Theme de bloques nativo para el sitio de Vicunav.

== Description ==

Vicunav implementa el homepage del estudio como un block theme nativo de
WordPress. Usa templates, template parts, patterns registrados, bloques core,
design tokens de theme.json y assets locales.

== Installation ==

1. Copia la carpeta vicunav dentro de wp-content/themes.
2. Activa Vicunav desde Apariencia > Temas.
3. Configura una página estática como portada.
4. Edita la portada, la cabecera y el pie desde Apariencia > Editor.
