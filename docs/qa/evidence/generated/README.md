# Evidencia generada

Esta carpeta acepta únicamente evidencia mecánica y revisable producida durante
QA: métricas JSON, matrices, manifiestos y resúmenes. No sustituye los baselines
ni la evidencia de regresión aprobada de una página.

Todo archivo generado debe enlazar el issue y el comando o fuente que permita
reproducirlo. Antes de versionarlo se valida estructura, ausencia de secretos y
coherencia con `docs/QA.md`.
