# Borradores generados

Esta carpeta contiene boilerplate o borradores mecánicos que todavía no forman
parte del theme. WordPress no carga ni ejecuta archivos desde esta ubicación.

Promover un borrador a `patterns/`, `templates/`, `parts/`, `inc/` u otra ruta
productiva exige revisión humana, issue trazable y todos los checks del destino.
Nada se considera implementado por existir aquí.
